# קהילה היא מארג של קשרים

דף סטטי שמציג את קבוצות הווטסאפ של קהילת רקפת כמעגלים. לחיצה על מעגל פותחת חלון עם פרטי הקבוצה וקישור להצטרפות.

להרצה מקומית: לפתוח את `index.html` בדפדפן. תוכן הקבוצות נמצא במערך `circlesData` בקובץ `community-circles.js`.
